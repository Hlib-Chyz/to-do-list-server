# ✅ To-Do List - Server

A backend application built with **NestJS**, using **Mongoose** and **Passport** for authentication.  
It features **user authentication**, standard **CRUD operations** for managing to-do items, and focuses on robust **validation** and **error handling**.

## 🔧 Technologies Used

- **NestJS**
- **Mongoose**
- **Passport (Authentication)**
- **MongoDB**
- **Class-validator / error handling**
